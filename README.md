## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22 writes `out/entry.png` using the checked-in illustration. The program runs offline with
the standard library. To regenerate the artwork locally on macOS, use Python 3 with Pillow and
run `python3 render.py`. The runtime does not need Python or fonts.
